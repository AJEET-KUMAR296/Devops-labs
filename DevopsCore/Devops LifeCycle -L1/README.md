# DevOps vs Agile - L1

## Problem Statement

The objective of this assignment is to understand how DevOps extends Agile principles.

Agile mainly focuses on improving software development through collaboration, continuous feedback, and frequent releases.

DevOps extends this approach by including deployment, operations, automation, and monitoring.

---

## Agile vs DevOps Comparison

| Feature | Agile | DevOps |
|---|---|---|
| Main Focus | Software development and faster delivery of features | Development, deployment, operations, and automation |
| Team Collaboration | Mainly focuses on developers, testers, product owners, and customers | Focuses on collaboration between development and operations teams |
| Deployment | Development may be completed in short iterations, but deployment can still be manual | Uses automation and CI/CD to make deployment faster and more reliable |

---

## How DevOps Extends Agile

Agile helps development teams create software faster through:

- Short development cycles
- Frequent feedback
- Team collaboration
- Continuous improvement

DevOps extends these principles by adding:

- Continuous Integration
- Continuous Delivery
- Continuous Deployment
- Infrastructure automation
- Monitoring
- Collaboration between Development and Operations teams
