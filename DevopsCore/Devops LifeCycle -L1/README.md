# DevOps Lifecycle - L1

## Overview

This project demonstrates the continuous nature of the DevOps lifecycle and explains its eight core stages: [ Plan, Code, Build, Test, Release, Deploy, Operate, and Monitor ].

The DevOps lifecycle connects software development and IT operations through continuous collaboration, automation, feedback, and improvement.

-----

## Objective

The objective of this assignment is to:

- Understand the eight stages of the DevOps lifecycle.
- Understand how each stage contributes to software delivery.
- Represent the lifecycle using a DevOps infinity-loop diagram.
- Understand why DevOps is considered a continuous process.

---

## DevOps Lifecycle

The DevOps lifecycle consists of the following eight stages:

| Stage | Description |
|---|---|
| Plan | Define project requirements, objectives, tasks, priorities, and development goals. |
| Code | Develop and manage the application source code using version control practices. |
| Build | Compile, package, and prepare the source code into a deployable application artifact. |
| Test | Validate the application through automated or manual testing to identify defects and ensure quality. |
| Release | Prepare and approve a tested version of the application for deployment. |
| Deploy | Deliver the approved application version to staging or production environments. |
| Operate | Manage, maintain, and support the application and infrastructure in the live environment. |
| Monitor | Continuously track application performance, availability, logs, and system health to identify improvements. |

---

## DevOps Infinity Loop

The DevOps lifecycle is commonly represented using an **infinity loop** to show the continuous relationship between development and operations.

The loop represents continuous:

* Development
* Integration
* Testing
* Delivery
* Deployment
* Operations
* Monitoring
* Feedback
## Stage Details

### 1. Plan

The planning stage defines business requirements, project scope, tasks, priorities, and the features that need to be developed.

Example tools: Jira, Azure Boards, Trello

---

### 2. Code

Developers write and maintain application source code while using version control systems to track and manage changes.

Example tools: VS Code, Git, GitHub

---

### 3. Build

The source code is compiled or packaged into an artifact that can be tested and deployed.

Example tools: Maven, Gradle, npm

---

### 4. Test

The application is validated to ensure that new changes work correctly and do not introduce defects.

Example tools: JUnit, Selenium, PyTest

---

### 5. Release

A stable and tested version of the application is prepared and approved for deployment.

Example tools: Jenkins, GitHub Actions, Azure DevOps

---

### 6. Deploy

The approved application version is deployed to a staging or production environment.

Example tools: Docker, Kubernetes, AWS, Microsoft Azure

---

### 7. Operate

The application and supporting infrastructure are maintained to ensure reliable operation in the production environment.

Example tools: Linux, Kubernetes, Docker, cloud platforms

---

### 8. Monitor

Application performance, infrastructure health, logs, errors, and availability are continuously monitored.

Example tools: Prometheus, Grafana, AWS CloudWatch, Azure Monitor


## How DevOps Works Continuously

DevOps does not end when an application is deployed.

After deployment, the application is operated and monitored. Monitoring data, user feedback, errors, and performance information are then used during the next planning stage.

## Conclusion

The DevOps lifecycle provides a structured and continuous approach to software development and operations.

The stages **Plan, Code, Build, Test, Release, Deploy, Operate, and Monitor** work together to support faster delivery, improved collaboration, automation, continuous feedback, and reliable software operations.
